# Тайны темперамента — сайт

Статический сайт-визитка школьного проекта: главная, рабочий тест из шести вопросов,
результаты исследования (60 учащихся), рекомендации по типу, ограничения и источники.

Сделан mobile-first: сначала 390 px, потом 768 px, потом десктоп. Без сборки, без
зависимостей, без интернета — открывается двойным щелчком по `index.html` или с любого
хостинга.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | вся разметка: hero, тест, история, теория, 4 типа, исследование, рекомендации, ограничения, о проекте, источники |
| `styles.css` | дизайн-система и адаптив (три брейкпоинта, sticky-CTA, reduced-motion) |
| `app.js` | логика теста, подсчёт результата, профиль, share-ссылка, табы, аккордеон, анимации |
| `data.js` | данные исследования: типы, увлечения, матрица сопряжённости, тексты рекомендаций |
| `manifest.webmanifest` | PWA-манифест (иконка, имя, цвет темы) |
| `assets/fonts/*.woff` | Artifakt Element — сабсет кириллицы + латиницы (Heavy, Medium, Book, Bold) |
| `assets/favicon.svg`, `assets/apple-touch-icon.png` | иконки |
| `assets/og-image.png` | превью для мессенджеров и соцсетей |

## Как пройти тест

1. Шесть вопросов о типичном поведении — по четыре варианта, каждый вариант относится
   к одному из четырёх типов.
2. Седьмой шаг — ведущее увлечение из пяти категорий (для видеоигр уточняется жанр).
3. Результат: ведущий тип и профиль по четырём шкалам, сильные стороны, рекомендации
   по досугу и учёбе.
4. Кнопка «Поделиться результатом» кладёт в ссылку параметры `?p=<тип>&h=<увлечение>` —
   открывший увидит тот же результат, тест заново проходить не нужно.

Ничего не отправляется на сервер: вся логика в браузере, ответы не сохраняются
(кроме параметров в ссылке, которой вы сами делитесь).

## Публикация на GitHub Pages (5 минут)

1. Создайте публичный репозиторий, например `temperament`.
2. Загрузите **содержимое папки `сайт/`** в корень репозитория (не саму папку):
   `index.html`, `styles.css`, `app.js`, `data.js`, `manifest.webmanifest`, `assets/`.
   Через веб-интерфейс: **Add file → Upload files**, перетащить всё сразу.
3. **Settings → Pages → Build and deployment**:
   Source — `Deploy from a branch`, Branch — `main`, папка — `/ (root)`. Сохранить.
4. Через 1–2 минуты сайт откроется по адресу
   `https://<ваш-логин>.github.io/<репозиторий>/`.

Проверьте с телефона: адрес должен открываться без установки приложения, а шрифт
должен остаться тем же (он лежит в `assets/fonts`, интернет для него не нужен).

### Свой домен (необязательно)

**Settings → Pages → Custom domain** → вписать домен → включить `Enforce HTTPS`.
У регистратора добавить `CNAME` на `<логин>.github.io`.

## Как поменять содержимое

- **Тексты рекомендаций и подписи типов** — `data.js`, объект `TYPES`.
- **Числа исследования** — `data.js`: `COUNTS`, `HOBBIES`, `MATRIX`. Диаграммы
  (донат, полосы, тепловая матрица) строятся из этих чисел и пересчитываются сами.
- **Вопросы теста** — `data.js`, массив `QUESTIONS`; порядок вариантов влияет на
  подсчёт, поэтому у каждого варианта явно указан тип.
- **Цвета и типографика** — `styles.css`, блок `:root`. Палитра: фон `#FBFAF8`,
  текст `#14161A`, линии `#E4DFD6`; акценты — сангвиник `#E8A33D`, холерик `#D9553F`,
  флегматик `#3A74B8`, меланхолик `#7B63AE`.
- **Мета-теги и OG-превью** — `index.html`, шапка; после смены домена обновите
  `og:url` и абсолютные пути к `og-image.png`.

## Шрифт

Сайт использует **Artifakt Element** (полная кириллица). В `assets/fonts` лежат
сабсеты в WOFF — этого достаточно для просмотра на любом устройстве, устанавливать
шрифт в систему не нужно.

Если понадобится собрать шрифты заново (другие веса или символы), исходные TTF лежат
в `../презентация/шрифты/`, а скрипт сабсеттинга — `../_build/make_fonts.py`
(нужен `fonttools`).

## Технические заметки

- Никаких внешних запросов: шрифты, иконки и картинки локальные. Сайт работает
  офлайн и не зависит от Google Fonts.
- Тест доступен с клавиатуры, у табов и аккордеона проставлены ARIA-атрибуты,
  при `prefers-reduced-motion` анимации отключаются.
- Проверено в Edge/Chrome на 390×844, 768×1024 и 1440×900.
